# CodeBridge

CodeBridge — личная облачная библиотека фрагментов кода. Вы сохраняете VBA, формулы или другой код на Mac, открываете ту же библиотеку на Windows и копируете исходный plain text одной кнопкой. Данные хранятся в Supabase, а интерфейс публикуется бесплатно через GitHub Pages.

## Что уже работает

- вход по email и паролю через Supabase Auth;
- создание, редактирование, автосохранение и ручное сохранение через `Cmd/Ctrl + S`;
- поиск по названию, описанию, тегам и коду;
- фильтры, сортировка, избранное, карточный и списочный вид;
- plain-text копирование с резервным способом для старых браузеров;
- Realtime-синхронизация и проверка при возвращении на вкладку;
- защита от конфликтов между устройствами;
- история версий, корзина, восстановление и окончательное удаление;
- светлая, тёмная и системная тема;
- экспорт и импорт Unicode JSON;
- адаптивный интерфейс и PWA-манифест;
- PostgreSQL-триггеры, индексы и Row Level Security.

## 1. Создайте проект Supabase

1. Откройте [supabase.com](https://supabase.com), создайте аккаунт и нажмите **New project**.
2. Укажите имя, надёжный пароль базы данных и ближайший регион.
3. Дождитесь готовности проекта.
4. В левом меню откройте **SQL Editor**, затем **New query**.
5. Скопируйте весь файл [`supabase/schema.sql`](supabase/schema.sql), вставьте в редактор и нажмите **Run**.

Сценарий создаст таблицы, индексы, историю версий, триггеры и правила RLS. Без авторизации данные не выдаются; вошедший пользователь видит только строки со своим `user_id`.

Если SQL Editor сообщает, что таблица `cards` уже добавлена в публикацию `supabase_realtime`, это означает, что Realtime был включён ранее. Уберите последнюю строку `alter publication…` и выполните сценарий ещё раз.

## 2. Добавьте первого пользователя

CodeBridge намеренно не показывает публичную регистрацию.

1. В Supabase откройте **Authentication → Users**.
2. Нажмите **Add user → Create new user**.
3. Введите email и пароль.
4. Включите автоматическое подтверждение email, если этот переключатель отображается.

Тем же аккаунтом войдите на Mac и Windows.

## 3. Подключите приложение к Supabase

1. В Supabase откройте **Project Settings → API** (в новом интерфейсе: **Connect**).
2. Скопируйте **Project URL**.
3. Скопируйте **anon public key** или **Publishable key**. Никогда не копируйте `service_role`/secret key в сайт.
4. Откройте [`js/config.js`](js/config.js) и замените:

```js
export const SUPABASE_URL = 'YOUR_SUPABASE_URL';
export const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
```

Ключ `anon` допустимо публиковать: безопасность обеспечивается RLS, а не секретностью этого ключа.

## 4. Проверьте локально

Из-за JavaScript-модулей файл нельзя надёжно открывать двойным кликом. В папке проекта запустите простой сервер:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Войдите созданным пользователем и создайте тестовую VBA-карточку.

## 5. Создайте репозиторий GitHub

1. На [github.com/new](https://github.com/new) создайте пустой репозиторий, например `codebridge`.
2. Загрузите в него все файлы проекта, сохранив папки `css`, `js`, `assets` и `supabase`.
3. Убедитесь, что в опубликованном `js/config.js` указан только URL и anon/publishable key.

Можно загружать файлы через кнопку **Add file → Upload files** — Git и командная строка не обязательны.

## 6. Включите GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
4. Через несколько минут GitHub покажет адрес вида `https://username.github.io/codebridge/`.

Все пути в приложении относительные, поэтому оно работает из подпапки репозитория. Добавьте итоговый URL в Supabase: **Authentication → URL Configuration → Site URL**. При необходимости добавьте тот же адрес в **Redirect URLs**.

## 7. Основной сценарий Mac → Windows

1. На Mac откройте GitHub Pages‑адрес и войдите.
2. Нажмите **Новая карточка**, вставьте код и сохраните.
3. На Windows откройте тот же адрес и войдите тем же аккаунтом.
4. Найдите карточку и нажмите **Копировать**.
5. В Excel нажмите `Alt + F11`, создайте Module и вставьте через `Ctrl + V`.

Браузер и PostgreSQL используют Unicode. Приложение не преобразует UTF‑8 в Windows‑1251, не форматирует код и копирует непосредственно поле `code`, а не HTML предпросмотра.

## Проверка VBA и кодировки

Сохраните и скопируйте на другом устройстве:

```vb
Option Explicit

Sub TestEncoding()
    Dim userName As String
    userName = "Данил"
    MsgBox "Привет, " & userName & "!"
    ' Проверяем русский комментарий
    Range("A1").Value = "Отчёт успешно создан — «готово»"
End Sub
```

Текст после вставки должен совпасть посимвольно. Поле редактора также поддерживает Tab и не включает spellcheck или автокоррекцию.

## Проверка безопасности

Создайте двух пользователей A и B. У каждого должны отображаться только собственные карточки. Запросы с anon key без пользовательской сессии должны возвращать пустой результат. Это обеспечивают policies в `schema.sql` для `SELECT`, `INSERT`, `UPDATE` и `DELETE`.

Для проверки XSS создайте карточку с `<script>alert("HACK")</script>`. Код должен отображаться текстом, а окно `alert` — не появляться. Интерфейс экранирует все пользовательские значения и не вставляет код как исполняемый HTML.

## Важные замечания

- Облачные карточки никогда не хранятся в `localStorage`. Там находятся только настройки интерфейса; текущий несохранённый черновик временно хранится в `sessionStorage`.
- История загружается только по нажатию **История**.
- При конфликте приложение не перезаписывает серверную версию молча.
- Настройки темы и вида в текущей версии локальны для устройства; структура `user_settings` уже подготовлена для облачной синхронизации.
- Для PWA на iPhone откройте меню Safari → **На экран «Домой»**. На настольных браузерах используйте кнопку установки в адресной строке, если она доступна.

## Структура проекта

```text
index.html              интерфейс
css/styles.css          адаптивный дизайн и темы
js/config.js            название и параметры Supabase
js/supabase.js          безопасная инициализация клиента
js/data.js              запросы и Realtime
js/clipboard.js         plain-text копирование и fallback
js/utils.js             форматирование, поиск и экспорт
js/app.js               состояние интерфейса и действия
supabase/schema.sql     таблицы, триггеры, RLS и индексы
manifest.json           параметры устанавливаемого приложения
assets/icon.svg         иконка
```

## Обновление

После изменения файлов загрузите их в ветку `main`. GitHub Pages опубликует обновление автоматически. Изменения структуры базы выполняйте через SQL Editor, предварительно сохранив экспорт библиотеки в **Настройки → Экспорт JSON**.
